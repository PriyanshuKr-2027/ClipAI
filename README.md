# ClipAI

Lightweight web app to analyze and edit short clips with captions and transitions.

## Quickstart

Prerequisites: `node` (>=16) and `npm` or `yarn`.

Install:

```bash
npm install
```

Run dev frontend:

```bash
npm run dev
```

Start server (if needed):

```bash
node server/index.js
```

Configuration:
- Copy `.env.example` or create a `.env` file. `.env` is ignored by git.

Build:

```bash
npm run build
```
